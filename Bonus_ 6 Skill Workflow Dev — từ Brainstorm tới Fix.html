🎁 Bonus: Bộ 6 Skill Workflow Dev cho AI Agent

Xuyên suốt khoá, bạn học cách giao việc bài bản cho AI Agent thay vì hỏi bừa. Đây là bộ 6 skill /ak hoàn chỉnh đóng gói đúng vòng đời làm phần mềm cùng AI — từ lúc bàn ý tưởng tới lúc sửa lỗi.

Tải về, nạp vào Agent (Claude Code) là dùng được ngay. Cũng là bộ khung mẫu để bạn tự thiết kế workflow của riêng mình.

Không cần giỏi code. Chỉ cần hiểu THỨ TỰ các bước và giao đúng việc cho Agent.

🧭 Thứ tự dùng (workflow chuẩn)

Bước Skill Dùng khi
1 /ak:brainstorm Bàn ý tưởng, cân nhắc phương án trước khi code
2 /ak:plan Chốt phương án → chia kế hoạch từng phase
3 /ak:cook Thực thi kế hoạch — viết code thật
4 /ak:test Chạy test, kiểm tra hành vi
5 /ak:code-review Soát chất lượng, bảo mật trước khi merge
6 /ak:fix Có bug → tự chẩn đoán rồi vá

Chuỗi điển hình: brainstorm → plan → cook → test → code-review, gặp lỗi thì fix.

⬇️ Bước 1 — Tải bộ skill

File nhẹ (~136KB), gồm 6 thư mục skill + README.md hướng dẫn workflow. Mỗi skill có SKILL.md mô tả quy tắc + quy trình để bạn đọc hiểu cách Agent được điều phối.

📦 Bước 2 — Cài đặt (một lần)

  1. Giải nén file .zip.
  2. Chép 6 thư mục ak-brainstorm, ak-plan, ak-cook, ak-test, ak-code-review, ak-fix vào kho skill của Claude Code:
~/.claude/skills/
  1. Mở lại Claude Code — các skill sẽ sẵn sàng gọi bằng lệnh gạch chéo.

▶️ Bước 3 — Dùng

Gõ lệnh tương ứng với việc bạn đang làm, ví dụ:

  • /ak:brainstorm — khi muốn bàn ý tưởng, cân nhắc phương án.
  • /ak:plan — khi đã chốt hướng, cần kế hoạch chi tiết.
  • /ak:cook — khi muốn Agent thực thi kế hoạch.
  • /ak:fix — khi có lỗi cần sửa.

Mẹo: đọc SKILL.md trong mỗi thư mục để hiểu Agent sẽ làm gì ở từng bước — đó chính là tư duy "giao việc" mà khoá học nhấn mạnh.
